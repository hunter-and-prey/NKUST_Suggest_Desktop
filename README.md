# 高科大校務建言桌面版

專為國立高雄科技大學（NKUST）師生打造的校務建言桌面應用程式，解決官方網頁填寫繁瑣、驗證易中斷的痛點，讓意見反映回饋更順暢、更省時。

---

## 🎯 它解決了什麼問題？

1. **不用每次重複填寫身分個資**：
   - 官方網頁每次填寫都必須手動重新輸入姓名、身分別、信箱、聯絡電話、保密選項及是否公開。
   - **本工具解決方案**：本機自動記憶常駐資料，開啟軟體直接聚焦於建言主旨與內容，省去 80% 重複操作。

2. **擺脫人工等待與手動點信箱確認連結**：
   - 官方建言送出後並未生效，系統會寄出一封「電子郵件驗證信」，使用者必須自行登入信箱、在 24 小時內翻找郵件並點擊驗證連結，若忘記點擊建言將直接作廢。
   - **本工具解決方案**：整合信箱自動驗證，送出後後端自動接收確認信並在背景直接完成驗證，建言立即正式立案生效；若已有收到驗證信，亦可隨時一鍵檢查並自動確認。

3. **字數限制與排版折算即時提示，防止送出失敗**：
   - 校務系統對主旨（限 20 字）與內容（限 1000 字，且每個換行強制折算 2 個字元）有嚴格限制，網頁端常在送出後才跳出錯誤要求重填。
   - **本工具解決方案**：即時換算字數與換行折算，以動態漸層顏色即時警示，輸入框更內建草稿即時暫存，絕不丟失任何辛辛苦苦寫好的內容。

4. **支援深色模式與現代化介面**：
   - 提供專為長時間閱讀與書寫設計的深淺色模式切換，搭配直覺的附件上傳與即時處理進度條。

## 💡 主要功能介紹

* **📝 撰寫與送出建言**：
  - 完整支援 38 個高科大行政與教學單位選單。
  - 即時字數統計與草稿本機保存。
  - 支援選取最多 3 個附件（PDF、Word、圖片等）。
* **⚡ 一鍵送出並自動確認**：
  - 秒速提交建言至校務系統，並自動在背景完成郵件驗證。
* **🔍 獨立信箱驗證按鈕**：
  - 若先前已透過網頁送出建言但尚未驗證，可直接點擊「立即檢查信箱並自動確認」，無須重新發送建言。
* **🌙 隨心切換深淺色主題**：
  - 頂部一鍵切換深色/淺色模式，自動記憶偏好。

## 🔐 信箱自動驗證與「應用程式密碼」使用說明

若希望啟用「**自動幫我點擊驗證信**」功能，需要提供一組 Google 專用的 **16 碼應用程式密碼 (App Password)**：

### 為什麼需要「應用程式密碼」？
高科大學生信箱（`@nkust.edu.tw`）由 Google Workspace 託管。為了保護帳戶安全，Google 禁止第三方軟體直接使用您的「Google 帳號主登入密碼」，而是要求建立專用的 16 碼通行密鑰。

### 如何取得 16 碼應用程式密碼？（只需設定一次）
1. 前往 **[Google 帳戶安全性設定](https://myaccount.google.com/security)**。
2. 確認帳戶已開啟 **「兩步驟驗證」**。
3. 搜尋或直接前往 **[應用程式密碼 (App Passwords)](https://myaccount.google.com/apppasswords)**。
4. 在「應用程式名稱」輸入自訂名稱（例如：`高科大校務建言`），點擊 **「建立」**。
5. 畫面會產生一組 **16 位英文字母**（例如：`abcd efgh ijkl mnop`）。
6. 開啟本軟體，切換至 **「⚙️ 常駐個資與信箱授權」** 分頁，將這 16 碼貼入 **「Google 應用程式密碼」** 欄位即可！

> 🛡️ **安全與隱私保障**：
> - **無法登入網頁**：應用程式密碼僅供 IMAP 讀取確認信使用，無法登入您的 Google 帳戶或變更個資。
> - **本機安全存放**：密碼僅儲存在您個人電腦的本機目錄中（若不希望儲存，每次填入當次使用即可），絕不上傳至任何第三方或雲端伺服器。
> - **隨時一鍵撤銷**：若不再使用，可隨時在 Google 帳戶安全性頁面一鍵刪除該組應用程式密碼。
